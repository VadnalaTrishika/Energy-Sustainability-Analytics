# Energy & Sustainability Analytics Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze energy consumption, utility expenditure, renewable energy generation and estimated carbon emissions across multiple sample facilities.

**Tools:** Power BI, DAX, CSV, Data Visualization

## Objectives
- Monitor electricity consumption and monthly trends.
- Compare energy usage across facilities.
- Analyze electricity, water and diesel utility costs.
- Track solar generation and estimated emissions.
- Enable interactive analysis using store and date slicers.

## Dashboard Features
- KPI cards for electricity consumption, utility costs, solar generation and estimated emissions.
- Monthly electricity consumption line chart.
- Store-level electricity consumption comparison.
- Utility cost breakdown donut chart.
- Interactive store and date filters.

## Dataset
The project uses a synthetic sample dataset covering five sample stores during 2025. It contains daily electricity, water, diesel, solar generation, utility cost, floor area and estimated emissions data.

**Disclaimer:** This is a practice project using simulated data. It is not affiliated with IKEA and does not use actual IKEA operational data. Utility rates and emissions factors are illustrative.

## Key Skills Demonstrated
- Data preparation and validation
- DAX measures
- KPI reporting and dashboard design
- Trend analysis and benchmarking
- Data visualization and business insight communication

## How to Use
1. Download the Power BI `.pbix` file and sample CSV.
2. Open the report in Power BI Desktop.
3. If prompted, connect the report to the downloaded CSV.
4. Use the store and date slicers to explore the data.
